## What this is

A tiny deterministic Node program for the make.fun bounty **"One Line, Big Laugh"**. It writes a single original one-liner (136 characters) to `/output/entry.txt`. No network calls, no clock, no randomness — the same input always produces the same output, every single run.

## The one-liner

> "My grandmother's Wi-Fi password is her maiden name, her first dog, and the year she stopped trusting the government, so I just use data."

## How to run

```bash
node main.ts
cat /output/entry.txt
```
